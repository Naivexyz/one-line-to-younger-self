# One Line to Your Younger Self

[![make.fun](https://img.shields.io/badge/make.fun-u--boothlord--one--line--to--your--younger--self--22e97f76-blue)](https://make.fun/competitions/u-boothlord-one-line-to-your-younger-self-22e97f76)

Entry for the make.fun competition **One Line to Your Younger Self**
(`u-boothlord-one-line-to-your-younger-self-22e97f76`).

## The line

> Stop saving the good snacks for later — later is you at forty, eating them alone over the sink.

## How it works

`main.ts` writes the single line to `/output/entry.txt` (mode `0644`).
The line is one breath, spoken straight to a younger self: a concrete,
lived-in image (hoarding the good snacks), a turn (`later is you`),
and a sting that is warm rather than sentimental — no slogan, no motto,
no second sentence doing the work.

## Run

```sh
node main.ts
cat /output/entry.txt
```
